## 我的学习目标

我希望通过这门课和持续的动手实践，把"会跟着教程敲代码"变成"能独立把想法做成一个真正能用的东西"。具体拆成五个方面：

### 1. 打牢编程基础

系统掌握 Python 的核心语法、常用数据结构（列表、字典、集合）与调试方法，能读懂别人写的代码，也能写出结构清晰的代码，而不是只会复制粘贴。目标是遇到一个新需求时，知道该用什么工具去解决，而不是先去搜现成答案。

### 2. 理解计算机系统怎么跑起来

搞清一台机器从硬件、操作系统、网络协议到 Web 应用是怎么一层层串起来的：一个网页请求从浏览器发出，经过 DNS、TCP、HTTP，最后落到服务器上的哪个进程、读的哪个文件。有了这层理解，排查问题时才不是"瞎试"。

### 3. 掌握 Vibe Coding（AI 辅助开发）

学会用 AI 协作完成真实项目，而不是只让它帮忙写小段代码。具体包括：

- **想清楚要什么**：能把模糊的想法拆成明确的需求、边界和验收标准
- **管住方案质量**：让 AI 先给方案再动手，比较取舍后再决定
- **卡住验收**：不轻信"改好了"，只认实际运行的输出和真实的测试结果
- **建立规范**：用项目说明书（Context）、可复用的工作流技能，让 AI 每次开工都少走弯路

### 4. 建立工程习惯

熟练使用 Git 管理版本（提交、分支、回滚），养成写测试、做验收、留文档的习惯。目标不只是"代码能跑"，而是"项目别人也能接手、以后自己也能维护"。

### 5. 积累可展示的作品

在课程期间完成若干个完整的小项目（例如班级管理小工具），每个都能讲清楚：它解决什么问题、我是怎么设计的、遇到哪些坑、最后怎么验证它真的能用。
