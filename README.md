## 我的学习目标

我希望通过这门课和持续的动手实践，把"会跟着教程敲代码"变成"能独立把想法做成一个真正能用的东西"。

首先是打牢编程基础。我想系统掌握 Python 的核心语法、常用数据结构与调试方法，能读懂别人写的代码，也能写出结构清晰的代码，而不是只会复制粘贴。我更希望遇到一个新需求时，自己知道该用什么工具去解决，而不是先去搜一个现成答案。

其次是理解计算机系统是怎么跑起来的。我想搞清一台机器从硬件、操作系统、网络协议到 Web 应用是怎么一层层串起来的——一个网页请求从浏览器发出，经过 DNS、TCP、HTTP，最后落到服务器上的哪个进程、读的哪个文件。有了这层理解，排查问题时才不至于只能"瞎试"。

这门课之外，我还在自学 Vibe Coding，也就是用 AI 协作完成真实项目，而不是只让它帮忙写小段代码。我希望自己能做到四件事：把模糊的想法拆成明确的需求、边界和验收标准；让 AI 先给方案再动手，比较取舍之后再决定；不轻信"改好了"，只认实际运行的输出和真实的测试结果；以及用项目说明书和可复用的工作流技能，让 AI 每次开工都少走弯路。这四项看起来都挺琐碎，但缺了哪一项，最后做出来的东西都会差点意思。

再往后是工程习惯。我想熟练使用 Git 管理版本，会提交、会开分支、也会在改坏了的时候回滚；养成写测试、做验收、留文档的习惯。我的目标不只是"代码能跑"，而是"项目别人也能接手、以后我自己也能维护"。

最后，我希望在课程期间做出几个完整的、能拿出来给人看的东西，并且能讲清楚它解决什么问题、我是怎么设计的、遇到过哪些坑、最后又是怎么验证它真的能用的。比起记住多少知识点，我更在意自己能不能把一件事从头到尾做成。


## 目录结构

```
cloud-computing-lab/
├── README.md              本文件：项目简介 + 自我介绍 + 学习目标
├── hello.py               第一个 Python 程序（个人信息卡片）
├── .gitignore             Git 忽略规则
└── student_cms/           python 学生管理系统（命令行增删改查 + 文件持久化）
    ├── student.py         Student 实体类（姓名 / 性别 / 年龄 / 电话 / 特点）
    ├── StudentCMS.py      管理类：增删改查、保存、加载、菜单循环
    ├── main.py            程序入口
    └── stu_data.txt       数据文件（程序退出时写入）
```

## 运行方法

需要 Python 3（开发环境为 Python 3.14.10）。

**一、个人信息卡片**

```bash
python hello.py
```

预期输出：一张包含姓名、班级、学号的信息卡片。

**二、学生管理系统**

```bash
cd student_cms
python main.py
```

按菜单提示输入编号：1 添加、2 修改、3 删除、4 查询单个、5 显示全部、6 保存、0 退出。数据保存在 `student_cms/stu_data.txt`，退出时自动写入，下次启动时自动读回。
